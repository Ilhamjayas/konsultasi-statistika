# Athenalytica — Konsultan Statistik

Desain website profesional dan minimalis untuk perusahaan konsultan statistik Athenalytica. Repositori ini berisi struktur halaman statis yang dapat digunakan sebagai dasar implementasi HTML/CSS/JS atau diintegrasikan ke framework modern seperti React.

## Struktur

- `index.html` — Struktur markup utama dengan section komprehensif (Home, Produk & Layanan, Tentang Kami, Testimoni, Kontak, dsb).
- `styles.css` — Gaya visual responsif menggunakan warna korporat ungu keemasan dan tipografi Poppins.
- `script.js` — Interaksi ringan (navigasi mobile, slider testimoni, penyesuaian tahun dinamis).
- `assets/` — Asset vektor pendukung (logo dan ilustrasi hero).

## Cara Menggunakan

1. Buka `index.html` langsung di peramban, atau integrasikan ke dalam proyek build tool favorit Anda.
2. Sesuaikan tautan WhatsApp, email, dan Google Docs sesuai kebutuhan operasional.
3. Ganti ilustrasi/asset jika memiliki materi visual resmi perusahaan.
